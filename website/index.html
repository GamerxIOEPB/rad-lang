Why Developers Choose Rad

Engineered from scratch for systems software, compilers, game engines, and performance-critical tooling.

🛡️

Memory Safety Without GC

Compile-time ownership semantics and borrow checking ensure memory safety without pause times or garbage collection overhead.

📦

Self-Contained Static PIE

Links directly with musl libc to generate fully static Position Independent Executables. No glibc version mismatch, zero runtime dependencies.

⚡

Self-Hosted Compiler

The compiler (radc) is written in pure Rad, compiling the entire toolchain in under two seconds with direct LLVM optimization.

🔗

Seamless C & C++ Interop

Direct C ABI calls with zero wrapper overhead. Automatic header binding extraction and C++ class bridge generation.

🛠️

Integrated Toolchain

Includes package manager (rad), test runner, compiler doctor (rad doctor), formatter, and diagnostics engine out of the box.

🔍

Helpful Diagnostics

Rich caret-underlined terminal compiler diagnostics with line and column spans and actionable error recovery.

Rad in Action

Clean, concise, and familiar syntax with modern type inference.

fn main() -> i32 {
    let greeting: str = "Hello, World from Rad!"
    let year: i32 = 2026
    
    println("{} - Welcome to {}", greeting, year)
    return 0
}
struct Point {
    x: i64,
    y: i64,
}

fn distance_sq(self: *raw Point) -> i64 {
    return self.x * self.x + self.y * self.y
}

fn main() -> i32 {
    let p = Point { x: 3, y: 4 }
    let d = p.distance_sq()
    println("Point({}, {}) distance squared: {}", p.x, p.y, d)
    return 0
}
fn fibonacci(n: i64) -> i64 {
    if n <= 1 {
        return n
    }
    return fibonacci(n - 1) + fibonacci(n - 2)
}

fn main() -> i32 {
    var i: i64 = 0
    while i < 8 {
        println("fib({}) = {}", i, fibonacci(i))
        i = i + 1
    }
    return 0
}
// Built-in zero-overhead C standard library calls
fn main() -> i32 {
    puts("Hello from C standard library puts!")
    system("echo 'Direct libc execution via Rad!'")
    println("Process finished successfully.")
    return 0
}

Quick Start Guide

Start building in three simple steps.

1

Install

Run the single curl command to automatically set up the self-hosted toolchain in ~/.rad.

2

Initialize

Create a new project in seconds using the package manager:
rad new my_app

3

Run

Compile and execute with instant native static PIE speed:
cd my_app && rad run

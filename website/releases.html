Quick Install (v0.2.1)
curl -fsSL https://raw.githubusercontent.com/GamerxIOEPB/rad-lang/main/scripts/install.sh | sh -s -- --version 0.2.1
Key Improvements & Features
  • Runtime Bounds Checking: Guard checks for arrays and slices with detailed diagnostic abort messages reporting index, length, and source location.
  • Zero-Division Safety: Automatic runtime trap handlers catching division and modulo by zero cleanly without crashing the process.
  • Range & Collection Loops: Full language support for for i in 0..10, for i in 0..=10, and for item in collection iterators.
  • Dynamic Slice Views: Return type inference and dynamic sizing for collection slices and sub-arrays.
  • Tuple Variable Swap: First-class generic swapping (swap(&mut a, &mut b)).
  • Statement Separator Diagnostics: Explicit enforcement of statement separation via newlines or semicolons with friendly compiler errors.
  • Expanded Test Suite: 188 automated regression, algorithmic (Bubble Sort, Merge Sort with up to 1,000 elements), and runtime safety tests.

💡 Managing Versions from the Command Line

The official Rad installer supports listing and installing any available release tag directly:

# Query all published release versions:
curl -fsSL https://raw.githubusercontent.com/GamerxIOEPB/rad-lang/main/scripts/install.sh | sh -s -- --list

# Install or switch to a specific version (e.g. 0.2.0):
curl -fsSL https://raw.githubusercontent.com/GamerxIOEPB/rad-lang/main/scripts/install.sh | sh -s -- --version 0.2.0

# Verify currently installed version:
rad --version
